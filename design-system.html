01 · Colour

Seven values, one accent, one stamp

The palette is deliberately narrow. One accent means every gold thing on the page is a signal (a link, a label, a state), so the visitor learns the vocabulary once and it holds everywhere. Red exists for exactly one object: the stamp on the file. Used anywhere else it would stop meaning ink.

Ink #0A0A0A

Page ground. Warmer than pure black so gold doesn’t vibrate against it.

Ink raised #0D0D0D

Alternating sections and card surfaces. Separation without a hard edge.

Brass #C88E5D

The only accent. Labels, links, states, focus rings. Nothing else is coloured.

Paper #E8E0D0

Reserved for the classified file card only, so it reads as a physical object.

Stamp #C41E3A

Ink. Used once, on the classified stamp, so it reads as a physical mark.

Text #F2EFE9

Off-white, not #FFF. Pure white on near-black is fatiguing to read.

Rule #222222

Every divider and border. Grid gaps expose it, so lines cost nothing extra.

04 · Motion & access

Rules I held to

  • Motion fires once. Reveals unobserve themselves after triggering. Nothing loops except the availability dot.
  • Every hover has a keyboard equivalent. Focus rings are visible and gold, never removed.
  • Reduced motion is honoured. Under prefers-reduced-motion the terminal sequence prints instantly and all transitions collapse to 0.01ms.
  • Nothing depends on JavaScript to be readable. With JS disabled every page still renders its full content; the reveals just never hide it in the first place.
  • One accent, one meaning. If it’s gold, it’s interactive or it’s a system label. No decorative gold. The single exception is red, and red only ever means ink on paper.
